# Mundialisimo

Proyecto web base con Next.js 16, React 19 y TypeScript.

## Requisitos

- Node.js 20+
- npm 10+

## Scripts

- `npm run dev`: servidor local de desarrollo
- `npm run build`: build de produccion
- `npm run start`: ejecutar build en local
- `npm run lint`: analisis estatico con ESLint

## Estructura minima

- `src/app`: App Router de Next.js
- `.vscode/tasks.json`: tarea Dev Server para VS Code
- `.github/copilot-instructions.md`: checklist de setup
